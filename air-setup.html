공기 보드 설치

컴퓨터에서 한 번만 하면 끝나요

이 브라우저는 보드에 연결할 수 없어요. 컴퓨터의 크롬, 엣지, 웨일에서 이 주소를 열어 주세요. (휴대폰·사파리에서는 안 돼요)
1

보드를 컴퓨터에 꽂기

  • 센서 케이블을 보드의 SENSOR 소켓에 꽂아요.
  • USB-C 케이블로 보드를 컴퓨터에 연결하고, 보드 스위치를 ON으로 켜요.
  • 이지온·아두이노 프로그램이 켜져 있으면 꺼 주세요. (보드를 같이 쓰면 연결이 안 돼요)
2

프로그램 넣기

아래 버튼 → 목록에서 USB 장치(COM…)를 고르고 연결 → 설치(Install)를 누르세요. 1~2분 걸려요.

이 브라우저는 지원하지 않아요. 컴퓨터의 크롬·엣지·웨일에서 열어 주세요. https 주소에서만 쓸 수 있어요.
목록에 아무것도 안 보이면
· 케이블이 충전 전용일 수 있어요. 데이터가 되는 USB-C 케이블로 바꿔 보세요.
· 보드의 BOOT 버튼을 누른 채로 RST를 한 번 눌렀다 떼고, 다시 시도해 보세요.
· 학교 컴퓨터에서 드라이버가 없다고 나오면 이지온 자료실(ezon.ai)의 보드 드라이버를 설치해 주세요.
3

휴대폰으로 핫스팟 정보 넣기

설치가 끝나면 보드가 설정용 와이파이를 켜요. 이제 컴퓨터는 필요 없어요.

  1. 휴대폰 설정 → Wi-Fi에서 EZ-CO2-SETUP-○○○○를 눌러 연결하세요. (비밀번호 없음)
  2. 설정 화면이 저절로 떠요. 안 뜨면 사파리에서 192.168.4.1을 여세요.
  3. 핫스팟 이름·비밀번호·장소를 적고 저장하고 다시 시작을 누르세요.
  4. 휴대폰 Wi-Fi 연결을 끊고 개인용 핫스팟을 켜 두세요. ('호환성 최대화'도 켜기)
아이폰 핫스팟 이름은 설정 → 일반 → 정보 → 이름에 있어요. 나중에 핫스팟을 바꾸고 싶으면, 보드가 1분 넘게 핫스팟을 못 찾을 때 설정용 와이파이가 다시 켜져요.
4

잘 되는지 확인

1~2분 뒤 휴대폰에서 에코쌤즈 → 공기 탭의 와이파이 보드 칸에 보드가 나타나면 성공이에요!
